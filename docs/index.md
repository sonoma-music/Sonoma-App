# Sonoma documentation

Sonoma is a free, open-source desktop music player for Windows and Linux. It plays the music you own, lights up lyrics word by word, brings your playlists over from other apps, lets you listen together with friends, and helps you build a lossless library from legal sources.

## Who these docs are for

- **Listeners**: start with [Getting started](getting-started.md), then read about the [library](library.md), [lyrics](lyrics.md), [import](import.md), [listening rooms](rooms.md) and [Get music](get-music.md).
- **Contributors**: read the [architecture](architecture.md), then [building from source](building.md). The [room server protocol](room-server.md) explains the WebSocket messages.
- **Everyone**: [privacy](privacy.md) lists every network request Sonoma makes, and the [FAQ](faq.md) answers common questions.

## Principles

1. **Your music, your files.** Sonoma plays files on your computer. It does not stream from or download from streaming services.
2. **Free and open.** Every feature is free. The code is MIT-licensed.
3. **Private by default.** No account, no ads, no tracking.
