# Getting started

## Install

**Windows 10 / 11:** download [Sonoma-Setup-0.1.0.exe](https://trysonoma.xyz/download/Sonoma-Setup-0.1.0.exe) and run it. The installer isn't code-signed yet, so Windows SmartScreen may show a warning: choose **More info → Run anyway**.

**Linux (x64):** download [Sonoma-0.1.0-linux-x64.tar.gz](https://trysonoma.xyz/download/Sonoma-0.1.0-linux-x64.tar.gz), then:

```bash
tar -xzf Sonoma-0.1.0-linux-x64.tar.gz
cd Sonoma-0.1.0-linux-x64
./sonoma
```

Prefer to build it yourself? See [building from source](building.md).

## Add your music

1. Open Sonoma. The Home screen says your library is empty.
2. Click **Add folder** and pick the folder with your music. Sub-folders are included.
3. Sonoma reads every MP3, FLAC, M4A, OGG, Opus, AAC, WebM and WAV file, with its tags and cover art, and groups the songs into albums.

You can add more folders later from Home or **Settings → Library**.

## Find your way around

| Sidebar icon | Screen | What it's for |
|---|---|---|
| House | Home | Your playlists, albums and recently added songs |
| Magnifier | Search | Search songs, artists and albums in your library |
| Bookmarks | Library | Favorites, playlists, all songs, and Import |
| Download | Get music | Links, free legal sources, downloads, CD ripping |
| People | Rooms | Listen together with friends |
| Gear (bottom) | Settings | Room server, Spotify keys, privacy, library, profile |

The player bar at the bottom shows what's playing. On its right: shuffle, repeat, lyrics, volume, copy smart link and the queue.

## Keyboard shortcuts

| Keys | Action |
|---|---|
| Space | Play / pause |
| Ctrl + → | Next song |
| Ctrl + ← | Previous song (or restart the current one) |
