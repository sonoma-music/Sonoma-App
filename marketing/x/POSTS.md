# Sonoma on X — launch kit

All files are in `marketing/x/out/`. Regenerate them with `python marketing/x/make.py`.

Replace these placeholders before posting:

| Placeholder | Replace with |
|---|---|
| `{CA}` | The real contract address (same as in the admin panel) |
| `{BURN_TX}` | Link to the burn transaction on the Robinhood Chain explorer |
| `{DEAD_ADDRESS}` | The dead / burn address the tokens were sent to |
| `{LAUNCH_TIME}` | Launch date and time with time zone, e.g. `Nov 20, 15:00 UTC` |

> **Only post the burn posts after the burn has really happened and the transaction is confirmed.** Never post a CA anywhere before it's live in the admin panel, and never promise price, returns or listings.
